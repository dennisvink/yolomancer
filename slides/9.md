# yolomancer Project Structure

Repository:

- `src/main.rs`
  The CLI, terminal UI, agent loop, permissions, tool dispatch, sessions, and Bedrock integration.

- `tools/`
  Python tools discovered at startup and exposed to the agent.

- `slides/`
  This terminal slide deck.

---

Runtime:

- `target/release/yolomancer`
  The built CLI binary.

- `~/.yolomancer/config.toml`
  Local credentials, workspace permissions, and tool role configuration.

- `~/.yolomancer/sessions/`
  Resumable conversation state.

For the workshop, the interesting surfaces are the agent loop, tool schemas, permission model, Python tool loading, and AWS tool boundary.
