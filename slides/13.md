# Ideation

If yolomancer is both the tool and the thing we are rebuilding, what should it become?

Think in capabilities, not features:

- What should the agent know how to do?
- What should remain deterministic Rust code?
- What should be a Python tool?
- Where should permissions be strict?
- Where would automatic arbitration help?
- What would make this useful for your daily work?

Goal:

Design something we can build today, with yolomancer, inside yolomancer.
