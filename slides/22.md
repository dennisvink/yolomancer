# Exercise: Agent Vector Search

Build a vector search capability for yolomancer.

It should be able to:

- store raw documents in S3
- write metadata and document indexes to DynamoDB
- store embeddings in S3 Vectors
- remove documents and their chunks
- retrieve nearest neighbours
- return citations back to the agent

Start simple.

Make the tool deterministic and inspectable.

---

Questions:

- What belongs in S3?
- What belongs in DynamoDB?
- What belongs in S3 Vectors?
- What is a chunk?
- When do we update embeddings?
- How do we delete stale information?
- How do we prevent irrelevant retrieval?
- How does the agent cite source documents?

Goal:

Give the agent project memory without blindly stuffing the prompt.
