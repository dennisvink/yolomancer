# YOLO Is Not a Production Strategy

Agentic systems are powerful because they are flexible.

That is also why they are risky:

- hallucinated facts
- plausible but wrong plans
- tool misuse
- repeated failed actions
- hidden cost explosions
- accidental data exposure
- "helpful" destructive behavior

Production agents need boundaries.

---

Use LLMs for intent, planning, language, and judgment.

Use deterministic components for domain truth:

- chess should call a chess engine
- Excel should call an Excel parser
- finance should call calculators
- cloud operations should call typed tools

Every tool call should have a permission shape:

- read
- write
- destructive

Add filesystem and network boundaries. Add approval and automated arbitration for dangerous or ambiguous calls.
