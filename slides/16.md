# Exercise: Write the Plan

Create `PLAN.md`.

Use checkboxes.

Structure it in phases so you can keep track:

- discovery
- design
- implementation
- tests
- polish
- documentation

Each checkbox should be a technical implementation story.

---

Example prompt:

```text
Read this repository and help me design a practical implementation plan.

Write PLAN.md with phased checkbox stories.

Each story should be small enough for an agent to execute safely.

Include tests and verification steps.

Do not edit production code yet.
```
