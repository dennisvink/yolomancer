# Extending yolomancer With Python

Python tools live in `tools/*.py`.

Each tool defines metadata:

```python
def yolomancer_tool():
    return {
        "name": "tool_name",
        "description": "When the agent should use this tool.",
        "parameters": {"type": "object", "properties": {}},
    }
```

And execution:

```python
def run(args):
    return {"ok": True}
```

---

Discovery executes only `yolomancer_tool()`.

Runtime executes `run(args)`.

This is RustPython, not CPython.

That means:

- no native CPython extension modules
- no arbitrary `pip install` ecosystem
- limited compatibility with packages expecting CPython internals
- good fit for deterministic workshop tools and lightweight automation
