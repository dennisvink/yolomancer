# Exercise: Execute a Slice

Pick one slice from `PLAN.md`.

Have the agent implement it.

Keep the scope deliberately small.

After the slice:

- run checks
- update the checkboxes
- inspect the diff
- decide whether to continue, revise, or revert

---

Create `LEARNINGS.md`.

Ask the agent to record:

- project context it discovered
- problems it encountered
- fixes it made
- assumptions it validated
- things it learned for future turns

This is a human-readable memory layer.
