# Built-In AWS Tools

yolomancer exposes AWS through two layers.

`aws_tool`

- model-friendly structured AWS operations
- STS identity
- S3 buckets and objects
- IAM users
- EC2 VPCs
- DynamoDB tables
- CloudFormation stacks
- Route53 hosted zones
- Account regions
- help for available operations

---

`aws_cli`

- fallback wrapper around the installed AWS CLI
- only exposed when `/sudo` is configured
- uses temporary assumed-role credentials internally
- no shell
- hard guards against credential leaks and unsafe local file access
- internally arbitrated unless YOLO mode is active

The intended pattern:

Use `aws_tool` first. Use `aws_cli` only for gaps, debugging, or CLI-specific behavior.
