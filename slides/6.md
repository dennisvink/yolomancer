# How Agents Think

An agent is usually a loop, not a single answer:

1. receive user intent
2. assemble context
3. ask the model what to do next
4. stream thoughts or summaries when available
5. call tools
6. inspect tool results
7. continue or stop

The model does not "run" the tool.

It proposes a structured call. The host application validates, executes, and feeds the result back.

---

Important control points:

- system prompt
- available tools
- context selection
- token and reasoning budgets
- stop conditions
- permission checks
- result formatting

Good agents are shaped by the loop around the model.

The LLM is the planner and language interface. The application is the operating system.
