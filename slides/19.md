# Context Strategies

Summarise aggressively

- pro: cheap and simple
- con: summaries can lose detail or preserve wrong assumptions

Write durable project notes

- pro: human-readable, reviewable
- con: grows stale unless maintained

Keep scoped plans

- pro: preserves intent and progress
- con: can become busywork

---

Use retrieval

- pro: load only relevant context
- con: needs chunking, ranking, and validation

Use deterministic indexes

- pro: fast, predictable, cheap
- con: needs explicit structure

Split work into slices

- pro: limits blast radius
- con: requires discipline and integration passes

The best answer is usually a mix.
