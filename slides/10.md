# Inside yolomancer

yolomancer implements the loop with:

- Bedrock Converse calls to Claude Opus
- real provider token usage
- streaming assistant output
- reasoning summaries where the model exposes them
- OpenAI-style tool schema translation
- transcript compaction and resumable sessions

---

The host owns the sharp edges:

- Rust-owned shell and file tools
- Python tool discovery and execution
- AWS operation wrappers
- `aws_cli` fallback with hard guards
- permission modes
- filesystem and network boundaries
- automatic arbitration for risky calls

The practical design question:

What should the model decide, and what should the runtime enforce?
