# Structure: Instructions and Skills

Agents need structure outside the chat window.

Common surfaces:

- `AGENTS.md`
  Repository-local operating instructions.

- Skills
  Reusable domain capabilities with triggers and workflows.

- References
  Larger knowledge files loaded only when needed.

- Scripts
  Deterministic helpers for calculations, parsing, validation, and formatting.

---

A typical skill shape:

```text
skill-name/
├── SKILL.md
├── references/
├── scripts/
└── assets/
```

`SKILL.md` usually contains:

- `name`
- `description`
- when to use it
- workflow steps
- output format
- anti-patterns
- pointers to references and scripts

The best skills are specific, actionable, and backed by deterministic helpers.
