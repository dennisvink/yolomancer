# Exercise: Store Project Memory in AWS

We want to store project data:

- `LEARNINGS.md`
- run logs
- plans
- decisions
- tool results
- embeddings
- reusable snippets

Which AWS services spring to mind?

How would each help?

---

Possible directions:

- S3 for durable raw objects
- S3 Vectors for nearest-neighbour search
- DynamoDB for metadata and document indexes
- CloudWatch Logs for run history
- EventBridge for async workflows
- Lambda for deterministic tool execution

Exercise:

Create tools that can:

- store documents and chunks
- update metadata
- query nearest neighbours
- remove stale records
- retrieve the original source from S3
